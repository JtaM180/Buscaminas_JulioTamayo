# Buscaminas

Este es un proyecto de Buscaminas hecho en Java con arquitectura MVC. Incluye manejo de excepciones, pruebas JUnit y ejecución en consola.

# Cómo ejecutar

1. Abre el proyecto en Eclipse
2. Ejecuta la clase `juego.Buscaminas`
3. Sigue las instrucciones en la consola

# Requisitos

- Java 17 o superior
- Eclipse IDE
- JUnit 5 para pruebas
